# Cursor Landing Page

A clean, modern **Cursor-inspired landing page** built using **HTML and CSS**. This project focuses on semantic HTML, clean UI, and developer-centric design inspired by AI-powered code editors.

---

## 🚀 Project Overview

This landing page is a frontend-only project designed to mimic the visual and UX style of **Cursor**, an AI-powered code editor. It uses a dark IDE-like theme, code preview sections, and minimal UI elements.

The goal of this project is to practice:

* Semantic HTML structure
* Clean CSS architecture
* Modern landing page layout
* Git & GitHub workflow

---

## 🛠️ Tech Stack

* **HTML5** (Semantic Tags)
* **CSS3**
* No JavaScript
* No frameworks

2. Open the project folder:

   ```bash
   cd Cursor-Landing-Page
   ```

3. Open `index.html` in your browser
